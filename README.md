# CourseScope

CourseScope is a lightweight website for students to review university courses—similar to how Glassdoor is used for company reviews.

## Features

- Browse candid course reviews
- Filter by course, minimum rating, and keyword search
- See average rating and review count instantly
- Submit new reviews via a form
- Local persistence via browser `localStorage`

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
